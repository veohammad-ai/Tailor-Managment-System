== Description ==
Tailor Flow PK is a professional custom tailoring management system plugin for WordPress.

== Installation ==
1. Upload the `tailor-flow` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
